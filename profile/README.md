Scaffold Studio
===============

> Deploy and command Stellar tokens, NFTs, and DAOs through conversation

AI copilots that let builders launch, operate, and transact on Stellar with natural language.

### Focus

- Natural language deployment: tokens, NFTs, and DAOs created through conversation
- Production-ready blueprints: audited Soroban contracts behind every flow
- MCP backend: a Model Context Protocol server that turns intent into contract operations
- [scaffold-studio-frontend](https://github.com/scaffold-studio-hq/scaffold-studio-frontend): the AI copilot UI
- [scaffold-studio-contracts](https://github.com/scaffold-studio-hq/scaffold-studio-contracts): Soroban blueprints for tokens, NFTs, and governance
- [scaffold-studio-mcp](https://github.com/scaffold-studio-hq/scaffold-studio-mcp): the conversational deployment backend
- [scaffold-studio-brand-assets](https://github.com/scaffold-studio-hq/scaffold-studio-brand-assets): shared brand kit
